# Banco de questões — Guarda Municipal de Manaus

Aplicação web de estudo para praticar questões relacionadas ao concurso da Guarda Municipal de Manaus. O projeto reúne questões por matéria e nível, oferece feedback após as respostas e apresenta um painel de desempenho.

## Funcionalidades

- Questões de múltipla escolha organizadas por matéria.
- Seleção adaptativa de dificuldade com base no desempenho.
- Acompanhamento de acertos e progresso no navegador.
- Persistência local usando `localStorage`.
- Interface em HTML, CSS e JavaScript, em arquivo único.

## Como executar

Não há etapa de compilação ou instalação de dependências. Baixe ou clone o repositório e abra o arquivo `app questões GCM` em um navegador moderno.

```bash
git clone https://github.com/ChagasJG40/App-de-quest-es-GCM-.git
cd App-de-quest-es-GCM-
```

Depois, abra o arquivo HTML no navegador. O progresso fica armazenado no navegador e dispositivo usados; limpar os dados do navegador pode apagá-lo.

## Tecnologias

- HTML
- CSS
- JavaScript
- Web Storage (`localStorage`)

## Observação importante

Projeto educacional e independente, sem vínculo oficial com a Prefeitura de Manaus ou com a Guarda Municipal. As questões e referências legais podem precisar de revisão e atualização; consulte sempre fontes oficiais e o edital vigente. O conteúdo não substitui orientação jurídica.
